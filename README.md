# Samudio Auto website

To keep building in Claude Code, unzip this folder, open it in Claude Code, and tell it what to do next (for example "wire up the contact form and deploy to Vercel"). Claude Code reads `CLAUDE.md` on its own; that file has the brand, prices, contact details and launch checklist.

To look at the site, open `site/index.html` in a browser. The phone layout reference is `design-reference/home-phone.html`.
